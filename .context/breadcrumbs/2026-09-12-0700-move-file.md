## Requirement

Implement `move_file(src, dst)`.

## Constraints

- Both paths must pass `validate_path()`
- Never overwrite
- Collision → `(1)`, `(2)` suffix
- Audit before/after
- Support dry-run
- Phase 1 safety rules unchanged

## Plan

1. Inspect existing safety API
2. Design tool interface
3. Implement
4. Unit tests
5. Manual sandbox test
6. Update architecture

## Decisions

- `dst` adalah direktori yang sudah ada, bukan nama file target.
- Tool hanya menerima **satu regular file**. Tidak menerima folder, glob, atau batch.
- Dry-run adalah default (`dry_run=True`). Dry-run tidak menulis audit record.
- Tidak pernah overwrite. Implementasi memakai `os.link` untuk mengklaim nama tujuan secara atomik, lalu `os.unlink` sumber.
- Cross-volume move tidak didukung oleh strategi `os.link` + `os.unlink`. Tidak ada fallback copy/delete.
- Collision memakai `resolve_collision()` dari `organize_files`, menghasilkan `file (1).ext`, `file (2).ext`, dst.
- Audit real execution:
  - `planned` sebelum filesystem attempt
  - `ok` / `succeeded` saat sukses
  - `failed` saat gagal
  - validation refusal dicatat sebagai `skipped`
- Source yang sudah berada di direktori tujuan diperlakukan sebagai no-op sukses dan tidak menulis audit.
