CONSTRAINTS KHUSUS
------------------
- rename_file() = rename in-place. BUKAN move antar folder.
  Kalau butuh pindah folder, delegate ke move_file().
- TIDAK boleh pakai os.rename / os.replace / shutil.move langsung
  ke user path tanpa lewat safety layer.
- TIDAK boleh overwrite. Target exists → suffix "(1)", "(2)", dst.
- Dry-run default True.
- Audit before AND after (kecuali dry-run, ikuti contract yang
  kamu putuskan dan dokumentasikan).
- new_name harus bare filename: tolak "/", "\", "..", ".".
- src == dst → tolak (no-op refusal).
- Case-only rename di Windows harus support lewat temp intermediate.
- Symlink menunjuk keluar root → tolak lewat validate_path.
- Jangan ubah Phase 1 files kecuali agent/tools/__init__.py.
