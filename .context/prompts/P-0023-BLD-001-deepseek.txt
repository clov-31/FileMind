DESIGN FREEZE (RINGKASAN ADR-001)
---------------------------------
Signature:
  rename_file(path, new_name, config, *, dry_run=True, audit=None, tier="local") -> dict
  Return dict: {success, message, data} — pola move_file/delete_file.

Refusal (11 poin):
  path invalid / out-of-root / tidak ada / bukan file reguler / directory /
  di dalam quarantine / symlink keluar root / new_name kosong /
  new_name "." atau ".." / new_name mengandung "/" "\" atau ".." /
  src.name == new_name (case-sensitive).

Collision:
  resolve_collision seperti move_file: name (1).ext, name (2).ext, dst.
  Case-only rename di Windows BUKAN collision → temp unique lalu final.

Dry-run:
  default True; tidak rename/link/unlink/mkdir user;
  audit planned → ok + detail="dry_run".
  Side effect FS hanya audit (+ AuditLog boleh mkdir parent log).
  Ini keputusan, pin dengan test.

Audit execute:
  planned → attempt (os.link + os.unlink; case-only dua tahap dengan
  planned masing-masing) → ok / failed.
  Refusal → skipped hanya jika dry_run=False.

Target:
  new_name bukan path → TIDAK validate_path(new_name).
  dst = parent / new_name. temp divalidasi must_exist=False.
  Tidak ada exemption validate_path.

FS:
  TIDAK pakai os.rename / os.replace / shutil.move ke user path.
  Claim nama via os.link lalu os.unlink source.
